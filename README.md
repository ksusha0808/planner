# Мой планер — как запустить

Приложение: задачи (на день и на неделю), календарь, деньги с копилками и целями.
Работает без Claude, ставится на телефон и ноутбук как обычное приложение, открывается и без интернета.

Есть три шага. Первый нужен обязательно, второй и третий — по желанию.

---

## Шаг 1. Выложить приложение на GitHub Pages (≈5 минут)

1. Зайди на github.com → справа вверху **+** → **New repository**.
   Название: `planner`. Тип: **Public**. Нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
   Перетащи **все файлы и папку `supabase`** из архива → **Commit changes**.
3. Открой **Settings → Pages**. В разделе *Build and deployment*:
   Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу
   `https://ТВОЙ-ЛОГИН.github.io/planner/`

**Как установить приложение:**
- **iPhone:** открой ссылку в Safari → «Поделиться» → «На экран “Домой”».
- **Android:** открой ссылку в Chrome → меню ⋮ → «Установить приложение».
- **Ноутбук:** открой ссылку в Chrome, Edge или Яндекс Браузере → значок установки справа в адресной строке.

Уже на этом шаге всё работает, но данные хранятся отдельно на каждом устройстве.

## Шаг 2. Синхронизация телефона и ноутбука через Supabase (≈10 минут, бесплатно)

1. Зайди на **supabase.com** → **Start your project** → войди через GitHub.
2. **New project**: придумай название (`planner`) и пароль базы (сохрани его где-нибудь).
   Регион — **Central EU (Frankfurt)**. Нажми **Create new project** и подожди пару минут.
3. Слева открой **SQL Editor** → **New query**. Вставь всё содержимое файла `supabase/setup.sql` → **Run**.
   Должно появиться *Success*.
4. Слева открой **Authentication → Sign In / Providers → Email**. Выключи **Confirm email** → **Save**.
   Так при регистрации не придётся подтверждать почту.
5. Открой **Project Settings → API Keys** (или **Data API**). Скопируй:
   - **Project URL** (вида `https://abcd1234.supabase.co`),
   - **anon public key** (длинная строка, начинается с `eyJ…` или `sb_publishable_…`).
6. В приложении открой **Настройки → Синхронизация**, вставь адрес и ключ → **Подключить** →
   введи почту и пароль → **Создать аккаунт**.
7. На втором устройстве вставь те же адрес и ключ → **Подключить** → **Войти** с той же почтой и паролем.

Данные синхронизируются при открытии приложения, после каждого изменения и раз в минуту.
Без интернета всё продолжает работать, а синхронизация пройдёт, когда сеть появится.

> Ключ `anon` можно хранить в приложении — это нормально. Чужие данные по нему не увидеть:
> база отдаёт каждому только его записи (правила в `setup.sql`).
> Бесплатный проект Supabase «засыпает», если им не пользоваться неделю. Данные не теряются,
> проект включается кнопкой **Restore** в панели Supabase.
> Если Supabase не открывается из России без VPN, приложение продолжит работать на каждом устройстве,
> а синхронизация догонит, когда соединение появится.

## Шаг 3. Дела на день в виджете календаря на телефоне (≈5 минут)

Приложение отдаёт задачи с датами как календарь-подписку. Телефон добавляет её в свой обычный календарь,
и задачи появляются в стандартном виджете календаря.

1. В Supabase слева открой **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Назови функцию **`calendar`** (именно так). Вставь всё содержимое файла
   `supabase/functions/calendar/index.ts` вместо примера → **Deploy function**.
3. Открой функцию → **Settings** (или **Details**) → выключи **Verify JWT** / **Enforce JWT verification** → **Save**.
4. В приложении открой **Настройки → Виджет календаря** → **Получить ссылку на календарь**.
5. Подпишись на календарь:
   - **iPhone:** нажми «Подписаться (iPhone)» → «Подписаться». Или вручную: Настройки → Календарь →
     Учётные записи → Добавить → Другое → «Подписной календарь» → вставь ссылку.
     В той же учётной записи можно выбрать, как часто обновлять календарь (например, каждые 15 минут).
     Потом зажми экран → **+** → виджет **Календарь** («Далее» или «Список»).
   - **Android:** на ноутбуке открой **calendar.google.com** → слева «Другие календари» → **+** →
     «Добавить по URL» → вставь ссылку. На телефоне добавь виджет **Google Календаря**.
     Google обновляет такие календари редко, раз в несколько часов. Задачи на завтра будут видны,
     а вот задачу, добавленную минуту назад, виджет может показать не сразу.

В календаре видны задачи с датой: со временем — как событие на час, без времени — как событие на весь день.
Выполненные отмечаются ✓, важные — ❗. Общие задачи на неделю в календарь не попадают, они есть в приложении.
Ссылку никому не показывай: по ней видны твои задачи.

## Как обновлять приложение

Если появится новая версия `index.html`, загрузи её в репозиторий (**Add file → Upload files**, с заменой).
В файле `sw.js` увеличь номер версии в строке `const CACHE = 'planner-v2.0'` (например, на `v2.1`),
чтобы телефон сразу подхватил обновление.

## Резервная копия

**Настройки → Резервная копия → Скачать копию** сохраняет все данные в файл.
Через **Загрузить копию** их можно вернуть или перенести.
